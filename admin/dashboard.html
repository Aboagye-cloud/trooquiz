Import questions from JSON

Add many questions at once to the subject chosen above. Paste your JSON or choose a .json file, check it, then import.

Mixes up which letter is correct, so students cannot guess a favourite letter. Turn it off only if an option says something like "all of the above".

See the format 
[
  {
    "question": "What does CPU stand for?",
    "options": [
      "Central Processing Unit",
      "Computer Personal Unit",
      "Central Program Utility",
      "Control Processing Unit"
    ],
    "answer": "A"
  },
  {
    "question": "What is 7 x 8?",
    "options": ["54", "56", "58", "64"],
    "answer": "56"
  }
]

Each question needs question, exactly four options, and the answer. The options can be a list of four, or an object with the keys A, B, C and D. The answer can be the letter A, B, C or D, or the exact text of the correct option. Other fields (such as id, difficulty or explanation) are ignored. The list can also sit inside {"questions": [ ... ]}. Up to 500 questions per import.
